Final-Year ML Project · 2022

Stress Detection System

Flagging early stress signals from everyday behavioral data.

Overview

Stress often shows up in behavior before someone would name it themselves. This final-year project builds a pipeline that collects everyday behavioral data, extracts meaningful features from it, and feeds a trained classifier that outputs a stress-level indicator.

Highlights
  • End-to-end pipeline: data collection → feature extraction → classification
  • Trained classifier outputs a stress-level indicator
  • Focused on everyday behavioral signals rather than self-reporting
